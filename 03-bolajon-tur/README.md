# Bolajon Tur — tur agentligi

Sayohat agentligi uchun bir sahifali veb-sayt. Faqat HTML, CSS va JavaScript.

## Imkoniyatlar
- Qidiruv paneli: aviachipta / mehmonxona / avtomobil / ekskursiya tablari
- Tur paketlarini filtrlash (dengiz, shahar, tabiat) va "barchasini ko'rsatish"
- Tarif rejalari, bron qilish oynasi, sevimlilar, mijozlar sharhlari slayderi
- Moslashuvchan dizayn va animatsiyalar

## Ishga tushirish
`index.html` faylini brauzerda oching.
