# Bolajon Life — sog'lom ovqatlanish markazi

Dietolog maslahati, ovqatlanish rejalari va sog'lom retseptlar sayti. Faqat HTML, CSS va JavaScript.

## Imkoniyatlar
- Kunlik kaloriya va tana massasi indeksi (TMI) kalkulyatori
- Retseptlarni nonushta / tushlik / kechki ovqat bo'yicha saralash
- Qabulga yozilish oynasi, video-slayd, animatsiyali statistika
- Moslashuvchan dizayn

## Ishga tushirish
`index.html` faylini brauzerda oching.
