# Bolajon Vet — veterinariya markazi

Veterinariya klinikasi uchun bir sahifali sayt. Faqat HTML, CSS va JavaScript.

## Imkoniyatlar
- 9 ta xizmat kartasi (bosilganda qabul formasida avtomatik tanlanadi)
- Qabulga yozilish formasi: tekshiruv, sana, filial, tasdiq xabari
- It/mushuk parvarish rejasi narx almashtirgichi
- Telefonda pastki "Qabulga yozilish" tugmasi, moslashuvchan dizayn

## Ishga tushirish
`index.html` faylini brauzerda oching.
