# Bolajon Market — maktab va ofis marketpleysi

Kanselyariya, daftarlar, ryukzaklar, ofis texnikasi va mebellari uchun internet-do'kon sahifasi. Faqat HTML, CSS va JavaScript.

## Imkoniyatlar
- Mahsulotlar JS ma'lumotlaridan chiziladi, kategoriya va chegirma bo'yicha filtr
- Jonli qidiruv (`/` tugmasi bilan ochiladi)
- Savat (miqdor +/−, jami, bepul yetkazish hisoblagichi) va sevimlilar — brauzerda saqlanadi
- Aksiya uchun teskari sanoq taymeri, kategoriyalar karuseli, moslashuvchan dizayn

## Ishga tushirish
`index.html` faylini brauzerda oching.
