# Bolajon Fresh — oziq-ovqat do'koni

Yangi meva, sabzavot, sut mahsulotlari va yong'oqlar internet-do'koni (to'q yashil dizayn). Faqat HTML, CSS va JavaScript.

## Imkoniyatlar
- Kategoriyalar va jonli qidiruv, mahsulotlar karuseli
- Savat: miqdor, jami summa, bepul yetkazishgacha progress chizig'i
- Kunlik aksiya taymeri, sevimlilar
- Moslashuvchan dizayn

## Ishga tushirish
`index.html` faylini brauzerda oching.

Rasmlar: [Unsplash](https://unsplash.com) (bepul litsenziya).
