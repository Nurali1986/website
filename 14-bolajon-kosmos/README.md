# Bolajon Kosmos — bolalar uchun o'yin va ta'lim

Maktabgacha yoshdagi bolalar uchun kosmik mavzudagi ta'limiy sayt. Faqat HTML, CSS va JavaScript.

## Imkoniyatlar
- 3 ta o'ynaladigan o'yin: Matematika missiyasi, Juftini top, Yulduzlarni sana
- Multfilm-hikoyalar (slayd shaklida) va uyda qilinadigan 4 ta ilmiy tajriba
- Yulduz yig'ish tizimi, haftalik chellenj, kosmonavt ismi — brauzerda saqlanadi
- Ota-onalar uchun 30 daqiqalik ekran vaqti taymeri

## Ishga tushirish
`index.html` faylini brauzerda oching.

Rasmlar: [Unsplash](https://unsplash.com) (bepul litsenziya).
