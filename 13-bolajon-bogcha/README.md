# Bolajon Bog'cha — maktabgacha ta'lim

Xususiy bog'cha uchun rang-barang sayt. Faqat HTML, CSS va JavaScript.

## Imkoniyatlar
- Bosh ekran matn slayderi, dasturlar kartalari
- Guruhlar bo'yicha kun tartibi (tablar)
- Tashrifga yozilish oynasi, foto galereya (lightbox)
- Moslashuvchan dizayn

## Ishga tushirish
`index.html` faylini brauzerda oching.

Rasmlar: [Unsplash](https://unsplash.com) (bepul litsenziya).
