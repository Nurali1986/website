# Bolajon xususiy klinikasi

Xususiy klinika uchun bir sahifali veb-sayt. Faqat HTML, CSS va JavaScript.

## Imkoniyatlar
- Moslashuvchan dizayn (kompyuter, planshet, telefon)
- Shifokorlar slayderi (avtomatik aylanadi, tugmalar bilan boshqariladi)
- Onlayn qabulga yozilish oynasi (shifokor va sana tanlash)
- Animatsiyali statistika, scroll animatsiyalari, mobil menyu

## Ishga tushirish
`index.html` faylini brauzerda oching.
