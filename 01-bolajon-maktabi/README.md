# Bolajon xususiy maktabi

Xususiy maktab uchun bir sahifali (landing) veb-sayt. Faqat HTML, CSS va JavaScript.

## Imkoniyatlar
- Moslashuvchan dizayn (kompyuter, planshet, telefon)
- Mobil menyu, sticky header, faol bo'limni belgilash
- Scroll animatsiyalari va raqamlar hisoblagichi
- Qabulga ariza oynasi (modal), video-slayd oynasi, yangiliklarga obuna

## Ishga tushirish
`index.html` faylini brauzerda oching.

Rasmlar: [Unsplash](https://unsplash.com) (bepul litsenziya).
