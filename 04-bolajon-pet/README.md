# Bolajon Pet — uy hayvonlari markazi

Grooming, trening, veterinariya, ozuqa va aksessuarlar uchun bir sahifali sayt. Faqat HTML, CSS va JavaScript.

## Imkoniyatlar
- "Blob" shakllari (jonli animatsiya) va panja naqshli dizayn
- Xizmatlar va aksessuarlar karuseli (avtomatik aylanadi, nuqtalar bilan)
- Savat: mahsulot qo'shish, o'chirish, jami summa, buyurtma berish
- Mijozlar sharhlari slayderi, aloqa formasi, moslashuvchan dizayn

## Ishga tushirish
`index.html` faylini brauzerda oching.
