# Bolajon Bog' — o'simliklar va landshaft

O'simliklar do'koni va bog' xizmatlari sayti. Faqat HTML, CSS va JavaScript.

## Imkoniyatlar
- O'simliklar katalogi filtr bilan (uy, sukkulent, bog')
- Narx kalkulyatori: xizmat turi va maydon (m²) bo'yicha taxminiy narx
- Tadbirlarga yozilish, galereya (lightbox, klaviatura bilan boshqariladi)
- Moslashuvchan dizayn

## Ishga tushirish
`index.html` faylini brauzerda oching.

Rasmlar: [Unsplash](https://unsplash.com) (bepul litsenziya).
