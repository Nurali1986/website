# Bolajon Aksessuar — aksessuarlar do'koni

Soat, sumka, ko'zoynak, quloqchin va zargarlik buyumlari internet-do'koni. Faqat HTML, CSS va JavaScript.

## Imkoniyatlar
- Avtomatik aylanadigan bosh slayder va 6 ta aksiya plitkasi
- Kategoriya bo'yicha filtr, qidiruv (kategoriya tanlovi bilan), qaynoq takliflar taymeri
- Savat (miqdor +/−) va sevimlilar — brauzerda saqlanadi
- Moslashuvchan dizayn

## Ishga tushirish
`index.html` faylini brauzerda oching.
